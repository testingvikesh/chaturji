2. SYLLABUS COVERAGE LOGIC

Question Paper Generate કરતા પહેલાં ERPએ સંપૂર્ણ Syllabusને:

Subject → Chapter → Topic → Sub-topic → Learning Outcome → Question Bank

આ રીતે Map કરવો.

Paper Generate કરતી વખતે:
• દરેક prescribed Chapterને યોગ્ય representation મળે.
• કોઈ Chapter completely ignore ન થાય.
• કોઈ એક Chapterમાંથી disproportionate questions ન આવે.
• એક જ Chapterમાંથી આખું Paper ભરાઈ ન જાય.
• શક્ય હોય ત્યાં સુધી દરેક Chapterના અલગ-अलग Topicsમાંથી પ્રશ્નો પસંદ થાય.

........

3. CHAPTER WEIGHTAGE

જો Teacher/Management દ્વારા Chapter-wise Weightage આપવામાં આવ્યું હોય તો તે Weightageને highest priority આપવી.
જો ન હોય તો chaptersને balanced / proportional representation આપવું.
કોઈ એક Chapterને unnecessarily વધારે weightage ન આપવું.

........

4. TOPIC DISTRIBUTION LOGIC

એક Chapterમાંથી પણ બધા પ્રશ્નો એક જ Topicમાંથી ન લેવા.
શક્ય હોય ત્યાં સુધી Topic Diversity રાખવી.
Same Topicમાંથી repeated questions avoid કરવા.

........

5. NO DUPLICATION RULE

• Exact duplicate question નહીં.
• Same question rephrased કરીને પણ duplicate નહીં.
• Same conceptનું ખૂબ જ similar question નહીં.
• Same answer માંગતા multiple questions avoid કરવા.
• Same example/case પરથી unnecessary repeated questions નહીં.
• એક જ Question Typeમાં duplicate નહીં.
• અલગ Question Typesમાં પણ શક્ય હોય ત્યાં સુધી same knowledge-point repeat નહીં.

........

6. QUESTION BANK DUPLICATION CHECK

દરેક પ્રશ્ન માટે Unique Question ID check કરો.
Paper Generate કરતા પહેલાં Question ID અને semantic similarity બંને check કરો.

........

7. PREVIOUS EXAM DUPLICATION

Previous Paperના questions scan કરો, previously used / similar questions avoid કરો, unused questionsને priority આપો.
Limited bank હોય તો Teacherને WARNING આપો.

........

Default: Easy={{difficulty_easy}}%, Medium={{difficulty_medium}}%, Hard={{difficulty_hard}}%.

9. LEARNING OUTCOME COVERAGE

મહત્વના Learning Outcomesમાંથી પ્રશ્નો આવવા જોઈએ.
